# my-docs
基于 MkDocs + GitHub Actions 自动部署到 GitHub Pages 的静态文档网站实践项目

## 项目简介
本项目使用 MkDocs 搭建技术文档网站，搭配 GitHub Actions 实现代码提交后自动构建并发布到 GitHub Pages，完成 Markdown 文档自动化上线。
